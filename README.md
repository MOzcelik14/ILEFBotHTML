# İLEFBot

![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-active-success)
![AI](https://img.shields.io/badge/AI-Gemini-orange)

İLEFBot, Bolu Abant İzzet Baysal Üniversitesi İletişim Fakültesi (İLEF) öğrencileri için geliştirilmiş deneysel bir yapay zekâ sohbet botudur.

Bot, Google Gemini modeli kullanarak öğrencilerin sorularına yanıt vermek, fakülte hakkında bilgi sağlamak ve çeşitli metin tabanlı etkileşimler üretmek amacıyla geliştirilmiştir.

Bu proje, büyük dil modellerinin üniversite toplulukları içinde nasıl kullanılabileceğini denemek amacıyla oluşturulmuştur.

---

## Amaç

İLEFBot'un geliştirilme amaçları:

* İLEF öğrencileri için hızlı ve erişilebilir bir bilgi aracı oluşturmak
* Yapay zekâ destekli öğrenci araçlarının kullanımını denemek
* LLM tabanlı uygulamaların üniversite ortamındaki potansiyelini araştırmak

---

## Özellikler

* Yapay zekâ destekli sohbet sistemi
* Fakülte bağlamına uygun yanıt üretimi
* Google Gemini tabanlı içerik üretimi
* Web tabanlı basit kullanıcı arayüzü

---

## Nasıl Çalışır

İLEFBot, kullanıcıdan gelen metin girdisini yapay zekâ modeline ileterek yanıt üretir.

Genel akış şu şekildedir:

Kullanıcı → Web Arayüzü → Serverless API → Gemini Modeli → Yanıt

Bu yapı sayesinde API anahtarları güvenli şekilde sunucu tarafında tutulur ve istemci tarafında paylaşılmaz.
